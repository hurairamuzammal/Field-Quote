Naming Conventions

Elements

Note: Each element should have a unique, generic name to avoid duplication. No element should have an auto generated name from Bubble.

Element
	
Naming convention to be followed 

	

	Groups
	G:
	G: Dashboard
	RepeatingGroups
	RG:
	RG: Items
	FloatingGroup
	FG:
	FG: Header
	ReusableElement
	RE:
	RE: Header
	

  


Style

Structure
Prefix: Indicate the type of element or the context.
Base Name: Describe the element with its properties. (size and colour)
Modifier: Add any specific state or variation.(weight)

 Example Format
heading-12pxBlack-400





Data Type

Relational Data field 
	Use keyword “related” at start and then table name when storing unique ids
	related_user
related_project 
	Option Sets
	Use Keyword “OS” at start then option set name. This prefix should be used for both The option set name in option set section as well as the data fields which has type option sets 
	OS role 
OS type 
	List 
	Use keyword “listof” when storing  list of  data
	listof_degrees
	List of relational Data  
	Use keyword “listof” when storing  list of  unique ids
	related_listof_users
related_listof_projects
