Bubble page structure

  1. Page bg #f1f5f9, min width 320
  2. FG Top bar (mobile): logo + menu — hide on desktop
  3. FG Sidebar (desktop): 72px icon-only or 200px with labels — Jobs + Profile only
  4. Group Main column: greeting → stats (optional) → week strip → seg tabs → hero → RG cards
  5. RG Jobs: type = Get My Jobs, 1 col mobile / 2 col ≥768
  6. Popup = bottom sheet style, fixed foot with action buttons
  7. No default Bubble calendar — use week strip + Today filter
